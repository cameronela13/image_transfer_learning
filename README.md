This project uses transfer learning with shallow and depp convolutional neural networks to classify images of nature and infrastructure. Four models with frozen weights were used. Each model's custom classification head was trained on augmented images and validated on originals with early-stopping for efficiency. Augments included cropping, translating, zooming, rotating, flipping, and contrasting. The models were compared on an unseen, original test set on precision, recall, F1 score, and ROC-AUC.
The pre-trained models come from TensorFlow. Their weights are downloaded from the respective model's Google API when the notebook is ran, using a temporary certificate on local devices. The notebook is set to run on 4 CPU cores.
